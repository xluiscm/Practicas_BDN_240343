Glosario

PK
Clave primaria: identifica cada fila.
FK
Clave foránea: enlaza una fila con otra tabla.
UNIQUE
Prohíbe repetir el valor o combinación señalada.
DEFAULT
Valor que MySQL aporta si el INSERT omite el campo.
AUTO_INCREMENT
Identificador que aumenta automáticamente.
Monovalorado / multivalorado
Una celda guarda un valor / una colección. Las columnas de este respaldo se clasifican monovaloradas.
Simple / compuesto
Un dato indivisible dentro del esquema / con partes separables definidas. Se marca simple salvo que el SQL muestre componentes estructurados.
Escala
Nominal: categorías; ordinal: orden; intervalo: diferencias; razón: diferencias y cero significativo.
Almacenado / derivado / proyectado
Guardado en tabla / calculado desde otros datos / aparece en una vista. La vista puede ser una proyección SQL que calcula o combina valores.

Ejemplos

ID con AUTO_INCREMENT: puede omitirse al INSERT, pero según DDL no admite NULL. Una columna DEFAULT puede omitirse aunque acepte NULL o no. Una FK es un dato almacenado que además limita a qué fila puede apuntar. Las vistas vw_trazabilidad_* proyectan información de tb_logs.

Valores de INSERT y datos de filas excluidos. Las clasificaciones funcionales son interpretaciones; tipos, NULL, DEFAULT, claves y atributos se verifican en el DDL.
